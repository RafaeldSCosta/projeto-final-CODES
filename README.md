# 🏠 MatchRooms

> Conectando pessoas ideais aos espaços ideais em São Paulo.

---

## 📌 Sobre o Projeto

O **MatchRooms** é uma plataforma web voltada para resolver um dos maiores desafios de estudantes e jovens profissionais que se mudam para São Paulo: **encontrar moradia acessível e compatível com seu estilo de vida**. 

Muitas pessoas possuem um quarto vago em casa e gostariam de dividir os custos, enquanto outras precisam de um lugar bem localizado, mas não têm orçamento para arcar com um aluguel sozinhas ou não conhecem ninguém na capital. O **MatchRooms** resolve esse problema através de um sistema de **compatibilidade de perfis (Match)**, unindo quem busca um quarto a quem tem um espaço disponível, priorizando a segurança e a afinidade de convivência.

---

## 🚀 Principais Funcionalidades

* **🏠 Home / Feed e Sistema de Match (`teste1.html`):** Página principal do sistema. Permite a visualização de perfis e quartos disponíveis com indicação de compatibilidade baseada nos interesses em comum.
* **🧪 Testes de Estrutura e Componentes (`index.html`):** Arquivo auxiliar utilizado para prototipagem e validação de estruturas e layouts complementares do projeto.
* **👤 Criação e Gestão de Perfil (`profile.html`):** Cadastro detalhado de informações pessoais, hábitos de rotina, preferências de convivência e faixa de orçamento.
* **⭐ Favoritos (`favorites.html`):** Área dedicada para salvar e gerenciar os quartos e perfis que mais chamaram a atenção do usuário.
* **💬 Chat Integrado (`chat.html`):** Interface de comunicação direta entre os usuários após a confirmação do "match", facilitando o alinhamento de detalhes e visitas.
* **🛡️ Foco em Segurança:** Estrutura pensada para verificação de perfis e transparência nas informações do imóvel e do anfitrião.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído do zero focando nos fundamentos do desenvolvimento web moderno:

| Tecnologia | Aplicação no Projeto |
| :--- | :--- |
| **HTML5** | Estruturação semântica de todas as páginas e acessibilidade. |
| **CSS3** | Estilização personalizada, layout responsivo e design moderno. |
| **JavaScript (ES6+)** | Lógica de interatividade, manipulação do DOM e simulação das regras de compatibilidade (match). |
